# 🚀 Smart Manager - Advanced File System Explorer

Smart Manager е модерно, високопроизводително и крос-платформено десктоп приложение, създадено за дълбоко сканиране, филтриране и масово управление на файлови системи. Разработено с Python и Flet.

## 📂 Архитектура на проекта (File Tree)

```text
📦 python-file-manager
 ┣ 📜 main.py                # Входна точка и UI контролер (View/Controller)
 ┣ 📜 operations.py          # Бизнес логика и файлови операции (Model)
 ┣ 📜 ui_components.py       # Персонализирани графични компоненти (CollapsibleDirectory)
 ┣ 📜 utils.py               # Помощни функции (естествено сортиране, System Shield пътища)
 ┣ 📜 generate_test_data.py  # Скрипт за генериране на контролирана тестова среда (Sandbox)
 ┣ 📜 test_all.py            # Пакет с автоматизирани модулни тестове (QA / Unit Tests)
 ┣ 📜 requirements.txt       # Списък със зависимостите на проекта
 ┣ 📜 .gitignore             # Игнорирани файлове за Version Control
 ┗ 📜 README.md              # Официална документация на хранилището
```

## ✨ Ключови функционалности
* **Дълбоко сканиране:** Рекурсивно търсене по времеви период (дата на модификация) и специфични разширения.
* **System Shield Защита:** Автоматично разпознаване на критични системни файлове (`.sys`, `.dll`, `/boot`) и блокиране на инцидентното им изтриване.
* **Smart UI:** Тъмна тема (Ultra Minimalist Dark), асинхронно рендиране и дървовидна структура с водещи линии.
* **Одитен Лог:** Генериране на детайлни текстови отчети (Audit Logs) преди масови операции.

## 🛠️ Инсталация и стартиране
Уверете се, че разполагате с Python 3.10+. За да стартирате проекта локално:

1. Инсталирайте нужните зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Стартирайте основния контролер:
   ```bash
   python main.py
   ```
